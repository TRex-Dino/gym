# Сайт тренировок

Сайт: https://trex-dino.github.io/gym/ — GitHub Pages из `main`, под телефон.

- `plan.js` — копия базы Notion «Упражнения» (страница «Сайт тренировок»). Источник правды — Notion; при изменении базы обновить `plan.js` и дату `updated`. Поле `id` не менять: на нём держится история на телефоне.
- `figures.js` — анимации-человечки (кинематика по углам суставов, темп 1 с вверх / пауза / 2–3 с вниз). Ошибки техники в анимации — это баги.
- `index.html` — приложение. Данные тренировок только в localStorage телефона (`gym2:ДАТА:A|B|R`); старые ключи `pullday:*` мигрируются, не удаляются.
- `sw.js` — офлайн-копия файлов сайта (network first). При добавлении файлов — добавить в список и сменить версию кэша.

Нельзя ломать: тёмную тему, таймер отдыха (зелёный с 1:30, «пора» на 2:00), копирование отчёта (текст + JSON: поля можно добавлять, существующие не переименовывать), историю на телефоне.
Сайт и репозиторий публичные: без личной и медицинской информации (кто назначил упражнение, диагнозы, даты приёмов). Шкалы боли на сайте нет — самочувствие пишется в заметку.
Главный принцип плана: здоровье суставов и спины важнее веса; вес +1 ступень, только когда техника не меняется.
